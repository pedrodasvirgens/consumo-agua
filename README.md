# Consumo de Água

## Sobre o projeto

O **Consumo de Água** é um programa desenvolvido em Python para classificar o perfil de consumo de água de diferentes tipos de imóveis.

O sistema solicita o tipo de imóvel e o consumo mensal em metros cúbicos (m³) e, a partir dessas informações, apresenta uma mensagem educativa de acordo com as regras estabelecidas pela companhia de saneamento.

## Objetivo

O objetivo do projeto é utilizar estruturas condicionais em Python para implementar um sistema simples de classificação de consumo de água e conscientização ambiental.

##  Como executar

1. Tenha o Python instalado em seu computador.
2. Abra a pasta `consumo-agua` no Visual Studio Code ou em outro editor.
3. Abra o arquivo `app.py`.
4. Execute o programa pelo terminal com:

    python app.py

5. Informe o tipo de imóvel quando solicitado:
   - comercial
   - casa
   - apartamento

6. Informe o consumo mensal de água em m³.

## Classificação

O programa utiliza as seguintes regras:

- **Comercial:** aplica a tarifa comercial.
- **Apartamento com menos de 10 m³:** consumo econômico.
- **Apartamento ou casa dentro dos limites definidos:** consumo moderado.
- **Demais situações:** consumo excessivo.
